## 🚀 Proyectos Destacados

### 🍽️ Atempo-App — Sistema de Gestión de Restaurante con IA

Sistema full-stack para gestionar pedidos de un restaurante. Los clientes pueden consultar el menú, realizar pedidos mediante un chat con IA y solicitar la cuenta, mientras que cocina, meseros y administradores cuentan con sus propios paneles de gestión.

* 🤖 Asistente de pedidos basado en IA
* 🧠 RAG mediante embeddings y `pgvector`
* 🦙 LLM local con Ollama y Llama 3.2
* 📱 Aplicación móvil con React Native y Expo
* 🔄 Comunicación en tiempo real mediante WebSocket/STOMP
* 📦 Gestión de pedidos e inventario
* 🔐 Autenticación y control de acceso

`Java 21` `Spring Boot` `React Native` `Expo` `PostgreSQL` `Ollama` `Llama 3.2` `pgvector`

---

### 📱 Sistema de Asistencia Universitaria

Aplicación móvil para registrar la asistencia universitaria mediante **códigos QR y reconocimiento facial**.

El sistema utiliza una arquitectura **serverless en AWS**, integrando servicios administrados para el procesamiento, almacenamiento y reconocimiento facial.

* 🔲 Registro de asistencia mediante códigos QR
* 📷 Reconocimiento facial con AWS Rekognition
* ☁️ Arquitectura serverless
* ⚡ AWS Lambda y API Gateway
* 🗄️ DynamoDB para almacenamiento
* 📱 Aplicación móvil con React Native y Expo
* 👥 Gestión de estudiantes, clases y registros

`Python` `JavaScript` `React Native` `Expo` `AWS Lambda` `API Gateway` `DynamoDB` `AWS Rekognition`

---

### 🎫 Soportia — Plataforma de Soporte Técnico

Plataforma web para gestionar soporte técnico interno, centralizando tickets, agentes, prioridades, SLA y operaciones administrativas.

* 🎫 Gestión de tickets, categorías, impacto y urgencia
* 🔐 Autenticación y autorización mediante Spring Security + JWT
* ⏱️ Gestión y escalación de SLA
* ⚡ Comunicación en tiempo real mediante WebSocket
* 🤖 Automatización de procesos con n8n
* 📊 Métricas y auditoría
* 🧪 Pruebas de aceptación con Playwright

`Java 21` `Spring Boot` `Angular 22` `TypeScript` `PostgreSQL` `WebSocket` `n8n` `Docker`

---

### 💳 PayCore — Plataforma de Pagos Orientada a Eventos

Plataforma de pagos simulados enfocada en **arquitectura orientada a eventos, consistencia y resiliencia en sistemas distribuidos**.

El sistema implementa diferentes mecanismos para manejar fallos, duplicidad de operaciones y comunicación entre servicios.

* ⚡ Arquitectura orientada a eventos con Apache Kafka
* 🔁 Transactional Outbox e idempotencia
* 🔀 Fallback y reintentos entre proveedores
* 🛡️ Circuit Breaker, Bulkhead y Timeout
* 💰 Procesamiento, liquidación y devoluciones
* 📄 Conciliación mediante archivos CSV
* 📊 Observabilidad con Prometheus, Grafana y OpenTelemetry

`Java 21` `Spring Boot` `React` `TypeScript` `PostgreSQL` `Apache Kafka` `Docker`
